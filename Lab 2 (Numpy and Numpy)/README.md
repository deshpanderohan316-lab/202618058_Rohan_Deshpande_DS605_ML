# Dataset-
Kaggle Titanic dataset (train.csv)

# Project details-
This project involved a comprehensive analysis of the Titanic passenger dataset using Python libraries including NumPy, Pandas, Matplotlib, and Seaborn. The analysis covered data loading, exploration, cleaning, transformation, statistical analysis, and visualization to uncover patterns in passenger survival.

# Key Observations
1. Gender Impact: Females had a significantly higher survival rate (approximately 74%) compared to males (approximately 19%), reflecting the "women and children first" protocol.

2. Class Influence: Passenger class showed the strongest negative correlation with survival (-0.34). First-class passengers had the highest survival rates, while third-class passengers had the lowest.

3. Fare Relationship: Higher fares were positively correlated with survival (0.26), as passengers paying more were typically in higher classes with better access to lifeboats.

4. Age Factor: Age showed a weak negative correlation with survival (-0.06), indicating children had slightly better survival chances.

5. Family Size: Creating FamilySize and IsAlone features revealed that traveling with family had some impact on survival, though correlations were weak.

6. Embarkation: Passengers embarking from different ports showed varying survival rates and fare distributions.

7. Outliers: Fare outliers were identified, with some passengers paying extremely high fares, indicating potential data anomalies or first-class luxury accommodations.
